This repository contains a personal developer portfolio built with Next.js. A terminal-style loading sequence introduces the site before revealing the main portfolio, with animated transitions and reusable sections.

## Sections

- Profile and introduction
- Skills and technology stack
- Experience
- Projects
- Campus involvement
- Certifications
- Resume call to action
- Contact details

## Tech stack

- Next.js App Router
- React and TypeScript
- Tailwind CSS
- Framer Motion
- Appwrite integration (where configured in the application)

## Run locally

### Requirements

- Node.js compatible with the Next.js version in `package.json`
- npm

```bash
git clone https://github.com/kishorekrrish3/My-Dev-Portfolio.git
cd My-Dev-Portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Available scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```

## Customization

Update the reusable section components and content data to keep the portfolio current. Check any Appwrite-backed features and environment configuration before deploying your own copy.
